# Support

## How to file issues and get help

This project uses GitHub Issues to track problems with the reviews chain and the verifier.
Please search the existing Issues before filing a new one to avoid duplicates.

For questions about the game itself (accounts, how to leave or delete a review), use the contact options on [lexismash.it](https://lexismash.it) or write to <f.rombaldoni@campus.uniurb.it>.

This repository is maintained by Francesco Rombaldoni, the author of LexiSmash, in his spare time: answers may take a few days.
